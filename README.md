# Sketch Analyzer AI 🎨

An AI-powered web app that analyzes your sketches and gives instant feedback.

## Features
- **Rating** — Get a score out of 10 for your sketch
- **Improvement Tips** — Know exactly what to work on
- **AI or Human?** — Detects whether the sketch is AI-generated or hand-drawn

## Tech Used
- HTML, CSS, JavaScript
- Groq API (Llama 4 Scout vision model)
- Google Fonts

## How to Run
1. Clone this repo
2. Get a free API key from [groq.com](https://groq.com)
3. Create a `config.js` file in the root folder:
```js
   const API_KEY = "your_groq_api_key_here"
```
4. Open `index.html` with Live Server (VS Code extension)
